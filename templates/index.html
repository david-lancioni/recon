Agnóstica à fonte de dados

Conecte-se a diferentes origens simultaneamente, conciliando desde arquivos de texto simples (CSV, TXT) até conexões diretas com os principais bancos de dados do mercado como SQL Server, Oracle, PostgreSQL, MySQL e SQLite.

Regras configuráveis

As regras de conciliação podem ser configuradas em diversos formatos (1:1, 1:N e N:N), realizando agrupamentos e cálculos como somatória, máximo, mínimo e média. Os resultados são automaticamente classificados como Batidos, Divergentes e Órfãos.

Algoritmo

Processa os dados via rotinas noturnas (batch) ou em tempo real (on-line). Os registros são classificados como batidos, divergentes e órfãos e disponibilizados para consulta e exportação.

Resultados em tempo real

Relatórios sintéticos e analíticos são gerados, bem como um dashboard representando a saúde dos dados da empresa. O controle de acesso por área garante a segregação dos dados.
